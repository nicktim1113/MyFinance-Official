Features

From the first transaction to the rhythm of the whole month.

MyFinance Go combines everyday tracking, AI assistance, shared sync, reports, and advanced finance tools into a clear workflow. Start free, then unlock more capabilities when you need them.

AI-assisted transaction drafts

Enter natural text such as "breakfast 85, metro 30, coffee 120 today" and the app helps turn it into transaction drafts. AI helps parse and organize; you still review before saving.

  • Review amount, date, category, and note before saving
  • Supports multiple drafts and local fallback parsing
  • Does not provide investment, tax, legal, or financial advice

Dashboard and report insights

Use the dashboard for current-period summaries, recent transactions, recurring candidates, and forward-looking cash flow, then review trends and rankings in reports.

  • Daily trends, category rankings, and period comparisons
  • Optional AI report summaries with supporting evidence
  • 14-day cash-flow view and recurring transaction hints

Multiple ledgers and shared sync

Keep daily life, travel, family, or shared expenses in separate ledgers. Sign in to use cloud sync and shared ledgers when multiple people need the same view.

  • SwiftData local records with Firebase sync
  • Ledger switching, shared members, and collaboration flows
  • Useful for individuals, partners, families, and travel groups

Budgets, assets, and offsets

Finance Management combines budget tracking, asset records, and offset tools for reimbursements, loans, repayments, and transactions that need to be settled.

  • Budget progress and category goals
  • Asset tracking with optional expanded limits
  • Offset net statistics and history review

Data and upgrades

Bring records with you, and upgrade only when it helps.

MyFinance Go uses a free basic version with optional subscriptions and non-consumable modules. This website describes the features; all purchases are handled by Apple App Store / StoreKit.

CSV import and export

Useful for cleaning up old records, backing up data, or moving from another tracking workflow.

Backups and restore purchases

Use backup/import flows and restore App Store entitlements from the Settings screen.

VIP subscriptions

Unlock more ledgers, collaboration, themes, AI allowance, and transaction capacity according to the in-app plan.

One-time modules

Advanced insights, asset expansion, CSV tools, and offset net statistics can be unlocked when needed.
